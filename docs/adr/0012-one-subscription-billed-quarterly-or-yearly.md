# 只有一個訂閱方案，季繳或年繳，每月 3,000 頁

原本的 Subscription 是年繳 US$20、每月 800 頁。重度讀者一兩天就用掉 400 頁，額度明顯不夠；換算每月 US$1.67，也只有同類外掛常見月費（約 US$5）的三分之一。一頁翻譯的成本只有 Claude Haiku 的兩次呼叫，平均約 US$0.00052（`docs/research/pricing-costs.md`），所以額度可以給得大方，限制它的其實是價格。Paddle 的標準費率（5% + US$0.50）只適用於 US$10 以上的商品，更低的要另外找 Paddle 談客製費率；我們不想多一份客製合約，而且那 US$0.50 固定費在 US$5 月繳裡就占 10%，所以不做月繳。所以改成：一個方案，季繳 US$15 或年繳 US$48，兩者都是每月 3,000 頁。

## 決定

- **只有一個方案，不分輕度、重度。** 訂閱者還太少，看不出用量分布，現在分級等於用猜的。每月 3,000 頁用滿時，API 成本平均約 US$1.56，一個方案就涵蓋得了重度讀者。
- **扣款週期只有季繳和年繳。** 季繳 US$15（每月 US$5），年繳 US$48（每月 US$4，省 20%）。季繳讓人先付少一點試試，年繳一年只付一次 Paddle 的 US$0.50 固定費。不提供半年繳：介於兩者之間，多一個選項只讓人更難決定。
- **標價含稅、只用美元。** 買家刷卡的金額就是定價頁上的數字，稅由 Paddle 從裡面扣。幣別換算交給 Paddle，某個地區使用者明顯變多時再設當地價格。
- **每月頁數上限是 3,000 頁，季繳和年繳都一樣，每月重置、不累積。** 重置日照舊是每個月的訂閱起始日。不累積是為了不讓季繳的人一次用掉三個月的量。
- **用「上限」而不是「不限量」。** 對外寫不限量、內部再設合理使用上限，碰到的人會覺得被騙。直接寫一個一般讀者用不到的數字比較誠實。
- **不做加購頁數。** 3,000 頁對大多數人夠用，還沒有資料證明需要加購。
- **Free Pages 從 50 頁提高到 100 頁。** 成本約 US$0.05，價格變高後讓人多試幾話。
- **每次扣款後 14 天內可全額退款，續約也算，不看用量。** 最常見的退款原因是忘了取消被續約扣款。就算有人用滿再退，一次的損失是 3,000 頁的 API 成本（約 US$1.56，P90 約 US$2.9），加上 Paddle 退款時很可能不退的手續費（季繳約 US$1.25），合計約 US$3～4；手續費退不退要跟 Paddle 確認。退款期在同一個月週期內，所以一次最多就是一個月的上限。退款後 Subscription 立刻結束。
- **同一個 email 只有第一次退款能在外掛裡申請，之後要寫信。** 只防一次不夠：退款後重新訂閱是新的月週期，用量從 0 算，「訂閱、用滿、退款」可以一直重複。所以 Paddle 核准過一次退款（外掛、paddle.net、後台建立的都算，續約的退款也算）就記下 email 的 hash，刪除帳號也保留；之後同一個 email 在退款期內看到的是「請寫信」，退款 API 也拒絕。退款政策加一句「同一個人反覆退款（包括用不同帳號）可能被拒，法律要求的除外」。條款寫「人」、程式只認 email：換 email 很容易，但要認出不同帳號是同一個人得比對付款資料，Paddle 也沒有跨 customer 的卡號指紋，現在的規模不值得做。收到退款信預設照退，因為擋下來的人若改走 chargeback，一筆 US$20 比套利本身貴；只有明顯重複套利才拒絕。
- **退款在外掛裡直接申請。** 按鈕只在退款期內出現。Worker 透過 Paddle 的退款 API 建立退款，UI 顯示「退款處理中」；Paddle 核准後才取消 Subscription，等待期間照常可以翻譯。先取消再等核准的話，萬一退款被拒，使用者會錢和訂閱都沒了。被拒時 UI 告知並請使用者寫信給我們。
- **季繳和年繳互換在下次扣款時生效，不按比例補差價。** 兩種週期的上限一樣，等待期間使用者不會少拿東西；按比例計算的金額難懂，也會和退款期纏在一起。Paddle 沒有「下次扣款時換價格」的內建功能，所以一開始不提供換週期的按鈕：想換的人先取消，期末後用另一種週期重新訂閱。
- **現有訂閱者到續約前維持原價，新上限馬上生效。** 先付錢的人不該因為改版吃虧。最壞情況下，這兩個年繳 US$20 的帳號每月用滿會小虧，到續約前合計約 US$13。

## 不直覺的地方

- **Paddle 核准退款不會取消訂閱**，要我們收到核准的 webhook 後自己取消，否則被退款的訂閱到期還會續約。自動核准的退款可能只送 `adjustment.created`、不送 `adjustment.updated`（Paddle 文件前後不一致），要先在 sandbox 實測。
- **paddle.net 上的退款申請由 Paddle 自己決定，不會問我們**（Paddle Refund Policy §7.1），所以程式擋不住從那裡反覆退款。我們收得到核准的 webhook，會記下 email，但不能拒絕；發現有人這樣套利，要附上證據寫信給 Paddle。Paddle 的政策本身也寫了有退款濫用的證據就不退（§1.3）。
- **退款處理中就刪帳號，刪除時就記成退款過**：核准的 webhook 之後對不到 Account、記不到 email，否則「申請退款、馬上刪帳號」就能一直退。萬一這筆退款後來被拒，這個 email 也只是之後要寫信而已。

## 待定

- 從 Free Pages 用完到付費的轉換 UX，另開 issue 討論。

## 不採用的做法

- **防重複退款：退款後重新訂閱不重置本月用量。** 也堵得住，但剛付錢就看到只剩 0 頁很難解釋。
- **防重複退款：看用量決定能不能退，或按比例退。** 會傷到忘了取消被續約扣款的人，文案變複雜，還要另外顧各地消費者法規。
- **只有年繳。** 最簡單，但年繳 US$48 是一次付不少錢，沒有讓人先少付一點試試的選項。
- **每月 4,000 或 5,000 頁。** 照平均成本算不會虧錢，但用 P90 成本算，年繳在 4,000 頁時就是小虧，5,000 頁會虧更多。3,000 頁已經比觀察到的重度用量（約每月 3,300 頁，含測試時的重新翻譯）少不了多少，先從這裡開始，之後要調高很容易，調低很難。
